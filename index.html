Añadir fotos

  1. Entra a la carpeta de fotos en GitHub.

    Sube las imágenes a fotos/. Crea subcarpetas para separar álbumes: fotos/viajes/, fotos/retratos/…

  2. Arrastra los archivos y confirma.

    En GitHub pulsa Add file → Upload files, suelta las fotos y haz Commit changes.

  3. Espera unos segundos.

    Vercel detecta el cambio, ejecuta npm run build y publica la galería con las fotos nuevas. No hay que tocar código.

Opcional: añade títulos y descripciones en fotos/info.json. Todo lo demás se genera solo.
